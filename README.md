# Project 1: Rule-Based AI Chatbot
Developed during the AI Engineering Phase at DecodeLabs.

## 🏢 Project Overview
This project establishes a deterministic "White Box" Logic Engine using pure Python control flow. It follows a strict Input-Process-Output (IPO) model to filter inputs, handle state loops, and eliminate hallucination risks completely.

## 🛠️ Architecture Features
- *Sanitization Layer:* Normalizes user text via case-reduction (.lower()) and whitespace trimming (.strip()).
- *Deterministic Control Flow:* Uses absolute conditional branches (if-elif-else) to route execution states.
- *Continuous Loop:* Sustains active terminal interaction until a safe break command is called.
